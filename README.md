# EarthOptics CS 2027 · Caderno de Campo e Painel

- `caderno.html`: caderno de campo (celular). Vendedor vê só os próprios clientes.
- `index.html`: painel do gestor (computador): Painel, Clientes, Leads, Amostradores, Consultorias e Usuários.
- `config.js`: endereço e chave pública do Supabase.

Login, dados e anexos ficam no Supabase (projeto `earthoptics-cs-2027`, região São Paulo). As regras de acesso estão no banco (`schema.sql`).
